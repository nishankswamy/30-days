# Day 05 — Web Scraper + Daily Email Digest

> **Week 1** · Automation that runs without you. Scrape a site you actually read.

## Stack
Python + httpx + selectolax + cron

## Build this
- Scrape and parse a real target site
- Dedupe against previously seen items (persisted)
- Format and email yourself a digest
- Scheduled via cron or GitHub Actions

## Stretch goals
- Respect robots.txt, add exponential backoff and a rate limiter
- Handle site structure changes gracefully instead of crashing

## If you're running out of time
Write to a file instead of emailing.

## Done when
A digest actually landing in your inbox

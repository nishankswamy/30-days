# Day 10 — Agent With Tools (No Framework)

> **Week 2** · Write the loop yourself. Knowing what LangChain hides is the point.

## Stack
Python, raw SDK, no agent framework

## Build this
- The agent loop: model call, tool parse, execute, feed result back
- 4 tools: web search, calculator, file read, shell
- Tool error handling — the model must recover, not crash
- Loop and cost limits

## Stretch goals
- Trace viewer UI showing each step's reasoning and tool call
- Parallel tool execution when calls are independent

## If you're running out of time

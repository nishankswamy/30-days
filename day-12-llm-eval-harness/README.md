# Day 12 — LLM Eval Harness

> **Week 2** · The most hireable project of the month. Companies need this and can't hire for it.

## Stack
Python + multiple model APIs

## Build this
- Take a prompt + dataset, run it across N models
- Rubric-based grading (LLM-as-judge with a defined rubric)
- Comparison report: quality, cost, latency per model
- Config-driven so a new eval is a YAML file, not code

## Stretch goals
- Track cost and token usage per run, with a budget cap
- Regression mode: fail CI if quality drops vs the last run

## If you're running out of time
Two models, one metric.

## Done when
Report artifact + README with a real comparison

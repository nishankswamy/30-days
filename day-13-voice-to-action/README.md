# Day 13 — Voice-to-Action Tool

> **Week 2** · Speech in, something real happens. Latency is the whole challenge.

## Stack
Whisper (local or API) + intent classification + a real integration

## Build this
- Audio capture and transcription
- Intent classification from the transcript
- Executes something real: creates a task, calendar entry, or note
- Confirmation step before acting

## Stretch goals
- Streaming transcription, sub-2s end to end
- Local Whisper so it runs fully offline

# Day 15 — HTTP Server From Scratch

> **Week 3** · Raw sockets. No framework. This is where the depth story starts.

## Stack
Python, Go, or Rust — sockets only

## Build this
- Parse HTTP/1.1 requests by hand
- Routing, static file serving, correct status codes
- Keep-alive connections
- Handle malformed requests without crashing

## Stretch goals
- Thread pool or async event loop, then benchmark against nginx and explain the gap honestly in the README
- Basic HTTP/1.1 chunked transfer encoding

## If you're running out of time
GET only, no keep-alive.

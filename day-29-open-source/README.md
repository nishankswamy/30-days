# Day 29 — Open Source Contribution

> **Week 4** · A merged PR on a known repo carries more weight than another side project.

## Stack
Whatever the library uses

## Build this
- Pick a library you actually used this month
- Find a real open issue (good-first-issue or a bug you hit)
- Read CONTRIBUTING.md properly
- Submit the PR with tests

## Stretch goals
- Fix a second issue in the same repo
- Improve their docs where they confused you

## If you're running out of time
A docs fix counts. A typo fix does not.

## Done when
PR link
